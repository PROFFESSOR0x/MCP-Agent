# 🍯 MCP-Agent

**حوّل أي chatbot يدعم Remote MCP إلى وكيل ذكاء اصطناعي يعمل على جهازك.**

اقرأ الملفات، وابحث داخل المشروع، وعدّل المحتوى، وشغّل الأوامر من خلال خادم MCP محلي، مع مستويات صلاحيات واضحة ومصادقة باستخدام Token.

[English](README.md) · [العربية](README_AR.md)

`ملف Python واحد` · `Linux / macOS / Windows` · `Python 3.10+`

## ماذا يفعل المشروع؟

شغّل `mcp_agent.py` واربط أي عميل يدعم Remote MCP بجهازك، بما في ذلك العملاء المتوافقون مع Claude وChatGPT. يوفّر الخادم أدوات تتيح للعميل:

- عرض المجلدات والبحث عن الملفات.
- قراءة الملفات النصية، وإرسال الصور للنماذج الداعمة للرؤية، وتحويل صفحات PDF المحددة — بما فيها الصفحات الممسوحة بالـ Scanner — إلى محتوى صور.
- البحث داخل النصوص باستخدام Regular Expressions.
- إنشاء الملفات وتعديلها وتطبيق Patch سياقي بصيغة unified diff، ثم نقلها أو حذفها وفق مستوى الصلاحيات.
- تنفيذ أوامر Shell وشيفرات Python، ما لم تعطّل التنفيذ.
- إتاحة نقطة اتصال MCP عبر ngrok، أو التشغيل محليًا دون نفق عام.

يمكنك اختيار لغة رسائل البرنامج من خلال `--lang` أو `-lang`. راجع قسم [اختيار اللغة](#اختيار-اللغة).

## الإعدادات الدائمة والسجلات

يحفظ MCP-Agent إعدادات المستخدم وسجلاته في `~/.mcp-agent/` بعيدًا عن مجلد المشروع. تُكتب السجلات اليومية في `~/.mcp-agent/logs/` مع تدوير عند 10 MiB والاحتفاظ بما يصل إلى خمس نسخ احتياطية. تسجّل استدعاءات الأدوات ومدخلاتها ومخرجاتها وأخطاءها، مع إخفاء القيم الحساسة وتحديد حجم المحتوى المسجّل.

```bash
# حفظ دومين ngrok ثابت مخصص لحسابك
python mcp_agent.py --save-domain your-name.ngrok-free.app

# استخدام الدومين المحفوظ تلقائيًا أو تجاوزُه مؤقتًا برابط عشوائي
python mcp_agent.py --auto
python mcp_agent.py --random-url

# عرض الإعدادات دون إظهار الأسرار وآخر السجلات
python mcp_agent.py --show-config
python mcp_agent.py --logs
```

يُنشأ ملف `.env` بصلاحيات قراءة وكتابة للمالك فقط على Linux/macOS. حافظ على خصوصيته لأنه قد يحتوي على ngrok authtoken.

## 🚀 التشغيل السريع

المتطلبات: Python 3.10 أو أحدث. تحتاج حساب ngrok فقط عند الرغبة في إنشاء رابط عام.

```bash
# قراءة فقط (الوضع الافتراضي)
python mcp_agent.py

# قراءة وكتابة وتنفيذ داخل مجلد مشروع محدد
python mcp_agent.py --access operate --workspace ~/myproject

# صلاحيات كاملة على الجهاز — استخدمه بحذر
python mcp_agent.py --access full

# تشغيل محلي دون ngrok
python mcp_agent.py --access read-only --no-ngrok

# واجهة عربية
python mcp_agent.py --lang ar

# واجهة إنجليزية
python mcp_agent.py --lang en
```

في التشغيل الأول، يفحص البرنامج المكتبات المطلوبة ويثبّت الناقص منها، بما فيها Pillow لمعالجة الصور وPyMuPDF لتحويل صفحات PDF إلى صور. على Linux وmacOS، ينشئ عادةً بيئة افتراضية مستقلة في `~/.claude_agent_mcp/venv` ثم يعيد تشغيل نفسه داخلها. احتُفظ باسم المجلد القديم للتوافق مع التثبيتات الحالية. إذا كان ngrok مفعّلًا وغير مُعدّ، اتبع التعليمات الظاهرة لتسجيل الدخول.

## اختيار اللغة

يمكنك اختيار العربية أو الإنجليزية باستخدام أيٍّ من صيغتي الخيار:

```bash
python mcp_agent.py --lang ar
python mcp_agent.py -lang ar

python mcp_agent.py --lang en
python mcp_agent.py -lang en
```

القيم المدعومة هي `ar` و`en`. إذا لم تمرّر الخيار، يفحص البرنامج متغير البيئة `MCP_AGENT_LANG` ثم لغة النظام، ويستخدم الإنجليزية إذا لم تكن اللغة المكتشفة عربية.

```bash
# تشغيل البرنامج باللغة العربية من خلال متغير البيئة
MCP_AGENT_LANG=ar python mcp_agent.py
```

يغيّر الخيار رسائل الطرفية ونصوص المساعدة. تبقى أسماء أدوات MCP وأوصافها باللغة الإنجليزية للمحافظة على التوافق مع العملاء.

## 🔌 ربط عميل MCP عن بُعد

1. شغّل الخادم وانسخ رابط Connector كاملًا من الطرفية. عند استخدام ngrok سيشبه هذا المثال: `https://your-domain.ngrok-free.app/<TOKEN>/mcp`.
2. في عميل MCP الذي تستخدمه، افتح إعدادات Connectors أو إعدادات المطوّرين وأضف Remote MCP Connector مخصصًا. في Claude.ai، المسار هو **Settings → Connectors → Add custom connector**؛ وقد تختلف الخطوات في العملاء الآخرين أو تتطلب إعدادات حساب معيّنة.
3. الصق الرابط كاملًا كما ظهر. التوكن جزء من الرابط، لذا تعامل مع الرابط كله باعتباره سرًا.
4. فعّل Connector داخل المحادثة واطلب مثلًا عرض ملفات مجلد العمل. يعتمد دعم ChatGPT على ميزات MCP المتاحة وإعدادات الحساب أو مساحة العمل.

العملاء الذين يدعمون Bearer Authorization يمكنهم استخدام نقطة الاتصال المنتهية بـ `/mcp` مع الهيدر `Authorization: Bearer <TOKEN>`.

## 🔐 مستويات الصلاحيات

| المستوى | القراءة | الكتابة | تنفيذ الأوامر | Workspace |
|---|---|---|---|---|
| `read-only` (الافتراضي) | أي ملف على الجهاز | لا | لا | اختياري |
| `operate` | داخل مجلد العمل | داخل مجلد العمل | نعم، إلا مع `--no-exec` | مطلوب |
| `full` | أي ملف على الجهاز | في أي مكان | نعم، إلا مع `--no-exec` | اختياري |

الأدوات غير المسموح بها لا تُسجّل في خادم MCP أصلًا. في وضع `operate`، تتحقق أدوات الملفات من المسارات بعد حل المسارات النسبية والروابط الرمزية لمنع الخروج من مجلد العمل.

### ⚠️ تنبيه مهم بخصوص تنفيذ الأوامر

**وضع `operate` ليس بيئة عزل أمنية (sandbox) عند تفعيل تنفيذ الأوامر.** أدوات الملفات مقيدة بمجلد العمل، لكن أمر Shell قد يصل إلى مسارات أخرى باستخدام صلاحيات حساب نظام التشغيل الذي يشغّل البرنامج. للحصول على تشغيل يقتصر على أدوات الملفات دون تنفيذ أوامر:

```bash
python mcp_agent.py --access operate --workspace ~/myproject --no-exec
```

لا تستخدم `full` إلا عند الحاجة، وشغّل البرنامج بحساب نظام تشغيل لا يمتلك إلا الصلاحيات المطلوبة.

## 🧰 الأدوات المتاحة

| الأداة | الوظيفة | `read-only` | `operate` | `full` |
|---|---|:---:|:---:|:---:|
| `get_access_info` | عرض مستوى الصلاحيات ومجلد العمل والنظام والإمكانات المفعّلة | نعم | نعم | نعم |
| `list_directory` | عرض محتويات المجلد، مع خيار العرض الشجري | نعم | نعم | نعم |
| `read_file` | قراءة النصوص وإرسال الصور بصيغة مرئية للنموذج، أو تحويل صفحات PDF محددة إلى صور بما فيها ملفات Scanner | نعم | نعم | نعم |
| `find_files` | البحث عن ملفات بالاسم أو النمط | نعم | نعم | نعم |
| `search_text` | البحث داخل النصوص باستخدام تعبير نمطي | نعم | نعم | نعم |
| `parallel` | تنفيذ ما يصل إلى 8 أدوات متاحة بالتوازي مع الحفاظ على ترتيب النتائج | نعم | نعم | نعم |
| `write_file` | إنشاء ملف أو استبدال محتواه | لا | نعم | نعم |
| `edit_file` | استبدال مقطع نصي محدد بدقة | لا | نعم | نعم |
| `apply_patch` | تطبيق تعديلات unified diff سياقية بدقة على ملف UTF-8 موجود | لا | نعم | نعم |
| `make_directory` | إنشاء مجلد | لا | نعم | نعم |
| `move_path` | نقل ملف أو مجلد أو إعادة تسميته | لا | نعم | نعم |
| `delete_path` | حذف ملف أو مجلد | لا | نعم | نعم |
| `run_command` | تنفيذ أمر Shell | لا | نعم* | نعم* |
| `run_python` | تنفيذ مقطع Python | لا | نعم* | نعم* |

`*` تتعطل أدوات التنفيذ عند استخدام `--no-exec`.

### قراءة الصور وملفات PDF المرئية

تعيد `read_file` ملفات الصور كمحتوى صور أصلي في MCP حتى يتمكن العميل الداعم للرؤية من فحص الصورة مباشرة. أما ملفات PDF فتحوّل الصفحات المحددة إلى صور بدل الاعتماد على النص المضمّن فقط؛ وهذا يدعم ملفات Scanner والملاحظات المكتوبة يدويًا والجداول والرسوم، دون الحاجة إلى OCR منفصل. تُطبّع الصور وتُصغّر قبل إرفاقها.

- `read_file(path="scan.png")` — إرفاق صورة للنموذج.
- `read_file(path="scan.pdf", page_start=3)` — تحويل الصفحة الثالثة فقط.
- `read_file(path="scan.pdf", page_start=3, page_end=6)` — تحويل الصفحات من 3 إلى 6 شاملًا.
- ترقيم صفحات PDF يبدأ من 1، والحد الأقصى 8 صفحات في الاستدعاء الواحد؛ قسّم النطاقات الأكبر إلى عدة استدعاءات.
- الحد الأقصى للصورة 40 MiB ولملف PDF هو 100 MiB، مع حد أقصى 8 صفحات لكل استدعاء.
- يجب أن يدعم عميل MCP والنموذج محتوى الصور والقدرات البصرية حتى يتمكنا من تفسيرها.

### أداة `parallel`

استخدم `parallel` لاستدعاء الأدوات المستقلة التي لا تعتمد نتائج بعضها على بعض. أرسل قائمة من العناصر التي تحتوي `tool` و`arguments` عند الحاجة:

```json
{
  "calls": [
    {"tool": "list_directory", "arguments": {"path": "."}},
    {"tool": "search_text", "arguments": {"path": ".", "pattern": "TODO", "glob": "*.py"}},
    {"tool": "read_file", "arguments": {"path": "README.md", "start_line": 1, "max_lines": 30}}
  ]
}
```

تُنفّذ حتى 8 استدعاءات بالتوازي، وتُعرض النتائج بترتيب الطلب الأصلي. يُتحقق من أن كل أداة متاحة ضمن مستوى الصلاحيات الحالي، وتُعرض أخطاء الاستدعاءات الفردية دون إسقاط بقية النتائج. لا يُسمح باستدعاء `parallel` داخل نفسها. لا تجمع خطوات تعتمد على نتائج بعضها، ولا تعدّل الملف نفسه من استدعاءات متزامنة. وتُعاد الصور الناتجة عن القراءة المتوازية كمحتوى صور أيضًا، بحد أقصى 12 صورة في الدفعة، بينما يُحدّ النص الإجمالي للنتائج بـ 30,000 حرف.

### أداة `apply_patch`

استخدم `apply_patch` لتعديلات الكود التي تحتاج إلى سياق حول الأسطر أو عدة تغييرات دقيقة. تستقبل الأداة unified diff لملف نصي واحد موجود بترميز UTF-8. يمكن تضمين ترويسة `---` و`+++` أو حذفها، لكن يجب أن تحتوي الرقعة على كتلة واحدة أو أكثر تبدأ بـ `@@`.

```diff
--- a/example.py
+++ b/example.py
@@ -1,3 +1,4 @@
 def greet(name):
-    return f"Hello {name}"
+    message = f"Hello {name}"
+    return message
```

تتحقق الأداة من تطابق سياق كل كتلة مع الملف الحالي. إذا لم تتطابق أي كتلة، تفشل العملية دون تعديل الملف. وبعد نجاح التحقق من جميع الكتل، تحفظ التغيير عبر ملف مؤقت واستبدال ذري. لا تنشئ الأداة ملفات ولا تحذفها؛ استخدم `write_file` لإنشاء ملف جديد. ويظل المسار خاضعًا لمستوى الصلاحيات، كما أن الأداة متاحة فقط في وضعي `operate` و`full`.

## ⚙️ خيارات سطر الأوامر

| الخيار | الوصف |
|---|---|
| `--access`, `-access` | `read-only` أو `operate` أو `full` (الافتراضي `read-only`، ويُقبل أيضًا `readonly`) |
| `--workspace`, `-w` | مجلد العمل الافتراضي؛ مطلوب مع `operate` |
| `--port` | المنفذ المحلي المفضّل (الافتراضي `8765`، ويُختار منفذ آخر إذا كان مشغولًا) |
| `--token` | تحديد Token يدويًا؛ وإلا يُولّد تلقائيًا. يدعم أيضًا `MCP_AUTH_TOKEN` |
| `--domain` | دومين ngrok ثابت اختياري |
| `--ngrok-authtoken` | Token الخاص بـ ngrok؛ أو استخدم متغير البيئة `NGROK_AUTHTOKEN` |
| `--no-ngrok` | التشغيل محليًا دون رابط عام |
| `--no-exec` | تعطيل أدوات تنفيذ Shell وPython |
| `--max-timeout` | أقصى مهلة لتنفيذ الأمر بالثواني (الافتراضي `600`) |
| `--lang`, `-lang` | لغة الواجهة: `ar` أو `en`؛ الافتراضي من `MCP_AGENT_LANG` أو لغة النظام |

### إعدادات مفيدة

```bash
# دومين ثابت وToken تحدده بنفسك (حافظ على سريته)
python mcp_agent.py --access operate -w ~/project --domain your-name.ngrok-free.app --token "YOUR_LONG_RANDOM_TOKEN"

# تشغيل محلي فقط
python mcp_agent.py --access read-only --no-ngrok

# تشغيل غير تفاعلي
NGROK_AUTHTOKEN=your-ngrok-token python mcp_agent.py --access operate -w /srv/app
```

تجنّب وضع الأسرار الحقيقية في سجل أوامر الطرفية أو لقطات الشاشة أو تقارير الأعطال العامة.

## 🧠 كيف يعمل؟

```text
عميل MCP ── HTTPS ──> ngrok (اختياري) ──> AuthASGI ──> FastMCP / Streamable HTTP
                                                           │
                                                           └── أدوات الملفات والتنفيذ
```

- يستخدم نقل MCP من نوع Streamable HTTP.
- يقبل التوكن من مسار الرابط أو من هيدر `Authorization: Bearer`.
- يقارن التوكن باستخدام `hmac.compare_digest`.
- يسجّل استدعاءات الأدوات في الطرفية.
- يوفّر الأدوات بحسب مستوى الصلاحيات وخيار تفعيل التنفيذ.

## 🛡️ قائمة أمان مختصرة

- اعتبر رابط Connector والتوكن بيانات اعتماد سرية. لا تنشرهما ولا تشاركهما.
- ابدأ بـ `read-only`، واستخدم `operate` لمشروع محدد عند الحاجة إلى الكتابة.
- في وضعي `read-only` و`full`، قد تشمل القراءة ملفات حساسة مثل مفاتيح SSH وملفات `.env`.
- تذكّر أن `operate` مع تنفيذ الأوامر ليس sandbox؛ استخدم `--no-exec` إذا لم تكن بحاجة إلى Shell.
- أوقف الخادم باستخدام `Ctrl+C` عند الانتهاء.

## 🩺 حل المشكلات

| المشكلة | ما يمكنك تجربته |
|---|---|
| فشل إنشاء venv على Debian/Ubuntu | ثبّت الحزمة: `sudo apt install python3-venv` |
| ظهور `ERR_NGROK_108` | قد توجد جلسة ngrok أخرى؛ أوقفها ثم أعد التشغيل |
| ngrok يطلب Auth Token | اضبط `NGROK_AUTHTOKEN` أو مرّره عبر `--ngrok-authtoken` |
| تعذّر اتصال Connector | تأكد أن الخادم يعمل وأن الرابط المنسوخ يتضمن `/<TOKEN>/mcp` كاملًا |
| فشل استيراد مكتبة MCP | يتطلب المشروع `mcp>=1.10,<2`؛ احذف بيئة المشروع الافتراضية ثم أعد التشغيل لإعادة إنشاء المكتبات |
| الأدوات لا تظهر في المحادثة | فعّل Connector داخل المحادثة الحالية وتأكد من دعم العميل لـ Remote MCP / Streamable HTTP |
